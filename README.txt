Yaqiz (يقِظ) - ScamShield AI hackathon prototype
Cloud Run service: yaqiz (europe-west1, project ultimate-delight-zwh20)
Domain: www.theyaqiz.com
Env: ANTHROPIC_API_KEY (secret), YAQIZ_MODEL (default claude-haiku-5-5), YAQIZ_ORIGIN_SECRET (optional, Cloudflare lock),
     YAQIZ_PER_IP_DAY (max 10, default 10), YAQIZ_GLOBAL_DAY (default 500)
No npm dependencies. Start: node server.js
Languages: Arabic, English, Urdu, Hindi, Tagalog (UI + detection keywords + AI replies). Tests: npm test.
